# Simple Pacman game • • • ⍩⃝
###### The whole project was done with ZERO AI use, any and all changes where done by researching on reddit and watching human made videos.
<img width="1536" height="814" alt="image" src="https://github.com/user-attachments/assets/8661355d-9bb6-4094-bf85-d8633f308c31" />
A simple app made with the built-in java awt/swing graphics library.
To create this simple Pacman game, i followed @ImKennyYip Youtube tutorial, which showed how to create the game loop, create a jframe and jpanel, draw images on the jpanel, load the game map using a tilemap, add click handlers to make the pacman move, create a simple algorithm to move each ghost at random, detect collisions between the pacman and ghosts, have pacman eat the food pellets, add a running score, and reset the game when pacman collides with a ghost. 
After completing the tutorial, i decided to add some changes to it, other than the full design change, i decided to add a "You Won!" text displayed after you successfully eat all the food, along adding an icon to the window.
hope you enjoy playing it!
